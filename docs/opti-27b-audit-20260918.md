# Auditoría Opti-27B — 2026-09-18

## Resultado

Opti-27B es una variante Qwen3.8 de 3,47 bpw que no es compatible con el
`llama.cpp` oficial: agrega tensores `corr.*` y requiere el runtime parcheado
de [AutomationOptimization/opti-runtime](https://github.com/AutomationOptimization/opti-runtime),
basado en el commit `6a1a922d269908a29cbd4b49c27e6a8e7fd10fae`. Se compiló una
build aislada CUDA para SM86, sin modificar el backend estable de LlamaCode.

## Pruebas locales

Máquina: 2× RTX 3090, P2P disponible. Runtime aislado `0.4.0-dev`, commit
`6a1a922d2`, CUDA arch 86, KV `q8_0`, Flash Attention, reparto por capas
`tensor-split 0.5,0.5`, batch/ubatch 512/128 y sampling conservador.

| Prueba | Resultado | Lectura |
|---|---:|---|
| Texto corto, dual, 16K | **232,56 PP / 39,14 TG** | Carga y generación correctas; Python válido |
| Texto corto, dual, 262K | **215,18 PP / 39,10 TG** | 262K carga y responde; no es una prueba de contexto lleno |
| Prefill largo, dual | **570,91 PP acumulado a 123.904 tokens** | Sin OOM/corrupción; la velocidad cae al crecer el contexto |
| Cuatro sesiones, 65K total | **105,4 PP y 21,6 TG por slot; ~86,4 TG agregado** | Las cuatro solicitudes terminan correctamente |
| Visión, 16K, reasoning off | **484,1 PP / 38,5 TG** | Descripción correcta del ícono de LlamaCode |
| Tool-use, reasoning off | Válido | Emitió `calculator({"expression":"2+2"})` |
| Visión/tool-use con reasoning on | No válido | La salida se degeneró en `/`; no usar esa combinación |

La memoria observada durante el servidor visual de 16K fue de 6.784 MiB y
7.300 MiB por GPU. Esto confirma el atractivo de la variante para reservar
VRAM a slots o contexto, pero no demuestra la cifra externa de “17 GB” para
cuatro sesiones completas.

## Comparación y decisión

Opti no reemplaza SOL: sus ~39 TG duales quedan por debajo de los ~102 TG de
SOL en código, no tiene BCB LC-H1, y el reasoning activado es inestable en el
runtime parcheado. Tampoco supera a Occamy en decode (~163 TG) ni a los mejores
perfiles de throughput. Su ventaja concreta es el menor peso, el contexto
262K cargable, la visión funcional con reasoning off y la posibilidad de
varios slots con una presión de VRAM baja.

Se agrega como perfil **experimental no predeterminado** para pruebas de
concurrencia/visión y contextos largos. No se asigna BCB, HE0 ni HE20 sin
integrarlo primero al harness LC-H1; los números de la publicación y su PPL no
se consideran resultados locales. El repositorio/runtime declara una licencia
de evaluación personal/no comercial y una advertencia de patente: revisar
esas condiciones antes de distribuirlo o usarlo comercialmente.

No se modificó el runtime estable, SOL, Windows ni el dropdown principal.
