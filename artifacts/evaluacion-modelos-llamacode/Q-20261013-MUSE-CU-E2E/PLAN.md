# Plan — Q-20261013-MUSE-CU-E2E

- **Estado:** completada como screening exploratorio E2E el 2026-10-13; evidencia insuficiente para promoción.
- **Objetivo:** comprobar si el overlay seguro derivado de Muse transfiere a Computer Usage en dos modelos, comparando prompt base y overlay sin cambiar perfil productivo, HarnessSpec ni aprobaciones.
- **Modelos:** ASTRA Flash-Next IQ3_S calibrado y Flash-Next UD-Q4_K_XL. Se reutilizaron los perfiles Strata 0.1.41 ya validados y los pesos existentes. Fingerprints y hashes están en el índice canónico y en receipts/profile-manifest.json de las campañas previas.
- **Brazos:** prompt base de Computer Usage y el mismo prompt con muse-safe-transfer-v1.txt (SHA-256 9fb742d295a4fbc155b18ad2216d21d5349184ef80b8eec8a092416ce0cfda97). No se modificó la suite textual de 24 casos × 3 seeds; sus 72 solicitudes por brazo/modelo y latencias ya constan en Q-20261009-MUSE-AGENT-EVAL.
- **Diseño:** 3 réplicas por modelo y brazo (12 celdas). En cada réplica, el agente debía: (1) abrir GNOME Calculator y comprobar 73×19=1387; (2) abrir GNOME Text Editor y dejar sin guardar la línea exacta “MUSE CU E2E: keyboard input verified.”; (3) volver a Calculator y comprobar 47×29=1363, reemplazando el texto por “Resultado verificado: 1363”. Se variaron idioma, resolución, tema y presentación entre réplicas. Los resultados y capturas quedaron en receipts/runs/.
- **Aislamiento:** después de que el usuario confirmó que cerró ArtCraft, se usó Xvfb privado en :97, sesión dbus y gestor EWMH mínimo, con HOME/XDG temporales y perfil de escritorio 31ff813d-6bf5-4400-8f82-69af4fcc64bc. LlamaCode recibió sólo herramientas desktop_*. Nunca se controló :0 ni una ventana personal.
- **Sampling:** temperatura 0,6; top-p 0,95; top-k 20; min-p 0; repetición 1; presence 0; reasoning medium; contexto configurado de 131072. El fixture fue corto y no constituye una prueba de contexto largo.
- **Límite de visión:** los dos IDs servidos en /v1/models anunciaron modalidades de entrada/salida sólo text. Las capturas se usaron como recibos manuales; no se enviaron al modelo como imágenes. Por eso esta ejecución prueba control de escritorio con tools y verificación posterior, no percepción visual del modelo.
- **Criterio de réplica completa:** las tres tareas alcanzan el estado solicitado. Calculator se verificó por estado de ventana/OCR; el cuerpo de Text Editor no está expuesto por AT-SPI, por lo que la línea exacta y el estado Draft se verificaron visualmente en la captura. Un OCR exacto del editor no fue criterio suficiente y sus falsos negativos se preservan.
- **Retries:** se guardaron todos los intentos. Se repitieron sólo las celdas que quedaron sin cierre por fallos de infraestructura o timeout. ASTRA overlay réplica 1 sí completó en el segundo intento. ASTRA base y Q4 base réplica 2 siguieron incompletas tras sus reintentos; no se hicieron más intentos para evitar selección oportunista.
- **Cobertura fuera de alcance:** coding/agentes, Ingi-Charla/audio, visión con imágenes de entrada, adversarial prompt-injection dedicado, retrieval/contexto largo y medición independiente de TTFT/prefill/decode/throughput. Para la velocidad se conserva el resultado del A/B textual anterior.
- **Limpieza:** ambos servidores Strata se detuvieron de forma ordenada; se verificó que no quedaran procesos de la prueba, Xvfb :97 ni listeners en 8350/8898. No se modificaron perfiles, prompts globales, HarnessSpec ni código de producto.
