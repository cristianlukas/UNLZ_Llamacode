### Fix general incorporado — IDs UIA numéricos

La inspección de CU13 mostró que algunos modelos serializan como JSON number un `control_id` decimal que UI Automation entrega como cadena opaca, por ejemplo `42.72462`. Las llamadas a `QJsonValue::toString()` daban vacío y fallaban `desktop_click_element` / `desktop_control_action`; el parser de seguridad tampoco encontraba la etiqueta de un control destructivo cuando el ID venía como número.

- `DesktopComputerUse::controlIdText` conserva strings y normaliza números con la representación JSON compacta de Qt. El dispatcher y la revisión de seguridad usan el mismo helper.
- `desktop_controls` y los schemas indican copiar exactamente el ID y enviarlo como string JSON con comillas. `docs/computer-use.md` documenta que el ID es opaco.
- Regresiones: helper para `42.72462`, compuerta wire que sigue reconociendo `Eliminar` con ID numérico, y una integración Windows UIA que lee un control cuyo ID es representable como número.
- CU13 prepara un XLSX de sólo lectura con fórmula y caché 8; Gemma lee antes y después de que el runner cierre el PID exacto entre turnos. El validador exige dos aperturas, dos lecturas de título/hoja, cero procesos remanentes y hash del archivo idéntico.
