## Decisión y continuación

La separación de cgroups está probada para un OOM sintético y el guard ya distingue presión del usuario de falta real de memoria. Esto reduce la probabilidad de que cerrar/reiniciar Codex termine una prueba y evita que una presión de PSI moderada con RAM holgada la aborte. No garantiza que el escritorio sobreviva a presión grave, fallo de kernel o driver.

Q35 se reanudó después de estos gates y completó las 12 celdas preregistradas (4 contextos × 3 seeds) en serie. No hubo OOM, swap de worker, aborto de monitor ni servidor residual. La regrade CPU-only pasó 8/8 pruebas y mostró que el parser JSON previo no aplicaba: el prompt pedía respuestas numeradas y no fijaba formato JSON. Las siete respuestas con `finish_reason=stop` son 8/8 semánticas; las cinco terminadas en `length` al cap `max_tokens=768` quedan parciales. A 1M, las tres semillas dieron 8/8; frente al promedio 131K, el request tarda ~10,6× más, decode cae ~41,9% y prefill ~32,9%. La capacidad de 1M queda demostrada para tareas que la necesitan, pero no hay ventaja general que justifique aumentar el default de 131K. El detalle por corrida está en Q35 `RESULTS.md`; decisión y regrade en `receipts/q35-matrix-final-decision.json` y `receipts/q35-semantic-regrade-01.json`.

## Q35 4 × 3 context matrix closed · semantic audit and decision

The supervisor reached all 12 preregistered context/seed cells serially; 12/12 returned HTTP 200 with the model loaded, and no infrastructure failure stopped the matrix. Seven responses ended with `stop`; five ended at the fixed `max_tokens=768` cap. There was no worker OOM, swap, monitor abort, or residual inference server. No Codex window closure occurred during this matrix. The last run, `1048576:2026103`, completed at 16:03:11Z; its server and listener shut down cleanly.

The initial exact-match grade was not a valid semantic measure: the response parser only accepted JSON, but the eight numbered requests never required JSON and the request did not specify a JSON response format. We preserved original receipts and preregistered an offline regrade that maps numbered answers to the matching request ordinal or accepts explicit answers inside the matching case block; it ignores quoted/revoked/distractor values and marks ambiguous answers unresolved. All same-seed expected answer maps match across context levels. CPU regressions passed 8/8. All seven completed responses score 8/8 semantically; the five `length` responses have partial coverage 6/8, 7/8, or 8/8 and remain explicitly incomplete. Full per-run audit: `receipts/q35-semantic-regrade-01.json`; preregistration: `receipts/q35-semantic-regrade-preregistration.json`; reproducible offline tool: `scripts/q35_semantic_regrade.py`.

At 1M, the model returned the exact eight expected values for three different seed fixtures after processing 1,001,463 tokens in the final run. Mean prefill/decode were 2,310.0/89.9 tok/s and mean request time was 434.82 s. At 131K, two completed runs were also 8/8; mean prefill/decode were 3,440.9/154.7 tok/s and mean request time 40.93 s. Thus 1M is technically usable for a workload requiring that input size, but this matrix does not establish an accuracy advantage over 131K and shows substantially lower throughput and higher latency. Keep 131K as productive default; use larger context only when required by the task. ASTRA, SOL, productive Flash-Next, PeritoSoft, profiles, and weights were untouched.

The priority scan found no further eligible GPU test: Flash-Next NInfer remains blocked by platform support; Qwen3.8-27B quality/speed are already measured without agent adoption; P2.1 is a code-hardening recommendation rather than model inference; OpenJet is blocked by the 64/65 block mismatch; the current RCO revision is closed; Swift awaits access/license/compatibility; Strata has no new primary claim. Reopen only when a material artifact, runtime, claim, access condition, or workload changes. Final summary receipt: `receipts/q35-matrix-final-decision.json`.
